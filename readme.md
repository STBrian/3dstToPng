**You can now use [py3dst](https://github.com/STBrian/py3dst) Python module to convert images and textures, check the usage to know more about how it works. The module has some display and conversion functions if you call it from the command line using**
```bash
python -m py3dst -h
```
This will show a message about its usage

## 3dstToPng
Scripts to convert recursively all the 3dst file supported to png files in a directory. 

Supported formats are RGBA8 and RGB8.

If you want to convert from png to 3dst, I suggest to conserve the original 3dst files in the same directory as the png.
